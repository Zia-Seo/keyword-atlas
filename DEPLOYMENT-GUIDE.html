// what to do

Add the Gemini API key & redeploy

⏱ 2 minutes

The final step. We securely give Vercel the API key from Step 1 so the AI can run.

  1. In Vercel, click your keyword-atlas project · click "Settings" tab at top
  2. Click "Environment Variables" in the left sidebar
  3. In the Name field, type exactly: GEMINI_API_KEY
  4. In the Value field, paste your key from Step 1 (starts with AIzaSy)
  5. Make sure all 3 checkboxes are checked (Production, Preview, Development)
  6. Click "Save"
  7. Click "Deployments" tab at top · click the three dots ⋯ on latest deployment · click "Redeploy"
  8. Confirm by clicking "Redeploy" in the popup
  9. Wait 30 seconds for the new deploy

If something breaks

common fixes
// troubleshooting
  • "Server is missing GEMINI_API_KEY" — You forgot to redeploy after adding the env var. Go to Deployments → Redeploy.
  • "Gemini API error 400" — Your key is wrong. Generate a new one at aistudio.google.com/apikey.
  • "Gemini API error 429" — You hit the 1,000/day free limit. Wait until tomorrow or upgrade.
  • "Function timeout" — Already handled by vercel.json (60s limit). If it still happens, switch to Standard depth instead of Deep.
  • Tool returns weird/empty results — The AI sometimes returns malformed JSON. Just click "Begin Research" again.
  • Page loads but nothing happens when I click button — Check that research.js is inside an api/ folder in GitHub, not at root level.
ⓘ Pro tip — updating your site
After your site is live, any change you push to GitHub auto-deploys to Vercel within 30 seconds. Just edit a file on github.com (click the pencil icon), save, and Vercel takes care of the rest.
